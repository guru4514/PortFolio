01 FULL-STACK · FINANCE

Pigmie.

A daily ledger that goes where the work is.

Collection agents need reliable records in the field. Pigmie combines local-first personal tracking with a shared workspace for teams.

  • IndexedDB for offline personal records
  • Firestore collaboration with role-based access
  • Approval queues and a customer passbook
  • JavaScript
  • Firebase
  • IndexedDB
  • Capacitor
Read case study ↗Live project ↗Source code ↗
Behind the build +

The design decision

Personal mode stores records locally; organization mode uses shared Firestore data. Separate modes keep the offline workflow useful while supporting team permissions and approvals.

Personal → IndexedDB
Organization → Firestore + access rules
Shared web code → Capacitor → Android

The linked project is the JavaScript/Firebase edition. A separate TypeScript rebuild ↗ is also on GitHub.

02 APPLIED NLP · DEVELOPER TOOLS

TalentRank Studio

The reasoning behind the ranking.

A resume analysis tool that compares job requirements with candidate skills, then surfaces the matches, gaps, and scoring components for review.

  • Python
  • FastAPI
  • Skill matching
  • Document parsing
Read case study ↗Source ↗
Behind the build +

Make scores inspectable

The pipeline parses PDF, DOCX, and TXT files, extracts skills, and applies role-specific weights. Exact matches and related skills contribute differently; results include evidence and missing requirements.

Resume → Parse → Skill taxonomy
Job context → Weighted scoring → Comparison

The repository includes parser and API tests for malformed uploads. Scores are heuristic matching signals, not measured hiring accuracy.

03 COMPUTER VISION · APPLIED ML

DrowseGuard

Turning a webcam feed into a useful signal.

A driver drowsiness prototype that tracks eye and mouth geometry, streams the camera feed, and reports fatigue indicators through a live dashboard.

  • Python
  • OpenCV
  • Flask
  • TensorFlow
Read case study ↗Source ↗
Behind the build +

A working baseline, with an optional model

OpenCV and facial landmarks provide eye aspect ratio (EAR) and mouth aspect ratio (MAR) measurements. An optional TensorFlow CNN adds eye-state classification when its model file is available.

Webcam → Landmarks → EAR / MAR
Optional CNN → State & alerts → Flask dashboard

A local prototype requiring a webcam. Lighting, camera position, and model availability affect behavior; it is not a validated road-safety system.

04 FULL-STACK · AGRICULTURE

AgroConnect

A more direct connection from farm to buyer.

A marketplace project with crop listings, farmer and buyer accounts, verified contact access, and an audit trail for contact views.

  • Node.js
  • Express
  • MongoDB
  • JWT
Read case study ↗Source ↗
Behind the build +

Access is part of the product

Public listings keep contact details masked. Authenticated, email-verified buyers can request contact information; the backend logs those views and rate-limits the endpoint.

Crop listings → Buyer verification
Authorized contact request → Audit log

The repository includes a local in-memory database mode for trying the application.
